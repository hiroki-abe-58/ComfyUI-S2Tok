# Image sources

`scenes.png` and `progress.png` show input frames and renders of S2Tok reconstructions of two videos from Wikimedia Commons, both by
FakirNL and licensed under CC BY-SA 4.0:

- [Groei door Joep Sterman, De Monchyplein, Arnhem - Timelapse walk around](https://commons.wikimedia.org/wiki/File:Groei_door_Joep_Sterman,_De_Monchyplein,_Arnhem_-_Timelapse_walk_around.webm)
- [Pegasus door Ed van Teeseling, Berg en Dalseweg, Nijmegen - Timelapse walk around](https://commons.wikimedia.org/wiki/File:Pegasus_door_Ed_van_Teeseling,_Berg_en_Dalseweg,_Nijmegen_-_Timelapse_walk_around.webm)

Changes: frames center-cropped and resized; the other tiles are renders (ComfyUI's Render Splat) of 3D Gaussians reconstructed from
those frames with S2Tok. The images in this folder are licensed under
[CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/). The videos themselves are not included in this repository.
